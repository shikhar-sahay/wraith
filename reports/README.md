# Reports

This folder stores generated Markdown experiment reports for the Wraith deployment.

## Contents

- Daily reports generated from JSONL telemetry
- Cumulative summaries when needed
- Curated analysis outputs that are ready to review or share

## Notes

- Raw telemetry stays in `wraith_logs/`.
- Historical Mumbai experiment artifacts remain preserved in `experiments/`.
- Reports here should not overwrite the preserved historical experiment files.
