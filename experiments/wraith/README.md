This folder documents the newer Wraith deployment artifacts.

## Contents

- Daily reports generated from `wraith_logs/`
- Cumulative summaries built from Wraith JSONL telemetry

## Workflow

1. Collect raw JSONL telemetry in `wraith_logs/`.
2. Generate Markdown reports into `reports/`.
3. Copy or organize curated Wraith experiment outputs here when needed.
